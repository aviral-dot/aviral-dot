# Aviral Bagjani — AI Engineer Portfolio

This branch contains the new portfolio build for **aviral.dev**.

## Direction

An interactive AI-engineering portfolio inspired by the idea of an engineering workspace rather than a conventional resume site.

### Core sections

1. **Build Mode** — identity-first hero with system-status language.
2. **System Profile** — concise positioning around agentic AI, RAG, LLM evaluation, and production infrastructure.
3. **Tech Lab** — interactive technology surface.
4. **Project Vault** — RAGFury and AgentFlow as the primary engineering case studies.
5. **Architecture Lab** — interactive representations of the actual project architectures.
6. **Experience** — Zeepty AI Engineering internship.
7. **Education & Proof** — IIIT Bhagalpur and measurable achievements.
8. **Let's Build** — GitHub, LinkedIn, email, and resume actions.
